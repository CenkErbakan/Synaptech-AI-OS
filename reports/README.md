# reports/

Günlük, haftalık, QA ve güvenlik raporları.

Raporlar **DEMO verisi içermez**. Her raporda “Veri kaynakları” bölümü bulunur.

## Adlandırma

| Tür | Yol |
|-----|-----|
| Günlük | `daily/YYYY-MM-DD-<ajan>.md` |
| Haftalık | `weekly/YYYY-Www-<konu>.md` |
| QA | `qa/YYYY-MM-DD-<görev-id>.md` |
| Güvenlik | `security/YYYY-MM-DD.md` veya `YYYY-Www.md` |

Şablonlar: `templates/`. Frontmatter: `title`, `type`, `project`, `agent`, `date`, `status`.
